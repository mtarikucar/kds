# Admin Guide

This section walks through the HummyTummy **admin panel** (the app you see after signing in), screen by screen. For each page it covers its **purpose**, **what you do there**, and day-to-day **tips**.

Audience: the restaurant **owner (ADMIN)** and **manager (MANAGER)**. Some screens are also open to the waiter (WAITER) and kitchen (KITCHEN) roles; the top of each page states which roles can access it.

<Callout type="info">
  The currency is **Turkish Lira (TRY)**. The left sidebar groups screens into six
  sections: **Business**, **Menu & Tables**, **Operations**, **Multi-Branch**,
  **Marketplace** and **Settings & Access**. Every core screen is free; only a screen
  tied to a paid module **doesn't appear** in the menu until you own that module
  (you never get a 403) — it shows up automatically once the module is yours.
</Callout>

## Which screens are free, and which need a module?

The core screens are **free forever**: no credit card, no licence, and an unlimited number of users, tables, products, categories and monthly orders. Only the screens listed below with a module or integration are paid; every paid item is **annual** and unlocks with the **HummyTummy Licence (₺2,990/year)** as a prerequisite.

| Screen | Feature flag | Requirement |
| --- | --- | --- |
| POS (Sales Screen) | `posAccess` | **Free core** |
| Kitchen Display (KDS) | `kdsIntegration` | **Free core** |
| QR Menu / QR Codes | — | **Free core** |
| Menu Management | — | **Free core** (unlimited products/categories) |
| Tables & Floor Plan | — | **Free core** (unlimited tables) |
| Orders | — | **Free core** |
| Customers | — | **Free core** |
| Users & Roles | — | **Free core** (unlimited users) |
| Devices, Bridges, System Health, branch hub | `multiLocation` | **Free core** (first branch free) |
| Custom Branding | `customBranding` | **Free core** |
| Stock & Inventory | `inventoryTracking` | **Inventory & Cost Management** module — ₺1,490/year |
| Reports & Analytics | `advancedReports` | **Advanced Reports & Analytics** module — ₺1,290/year |
| Reservations | `reservationSystem` | **Reservation System** module — ₺990/year |
| Personnel | `personnelManagement` | **Staff Management** module — ₺990/year |
| Integrations / Webhooks | `apiAccess` | **API & Webhook Access** module — ₺2,490/year |
| Partner Display API keys | `externalDisplay` | **Partner Display API** module — ₺1,990/year |
| Online Ordering (delivery platforms) | `deliveryIntegration` | Platform integration — **₺2,490/year** (Yemeksepeti, Getir, Trendyol Yemek; per platform) |
| Second and further branches | `limit.maxBranches` | **Extra Branch** — ₺3,990/year each (first branch free) |

<Callout type="info">
  For the full list of paid items and their prices see **[Plans](/en/plans)**.
  For step-by-step setup of external connections such as delivery (Yemeksepeti/Getir),
  SMS, e-Invoice and Caller ID see **[Integrations](https://developer.hummytummy.com/en/integrations)**; for the
  purchasable modules and integrations see **[Marketplace](/en/marketplace)**.
</Callout>

<Callout type="warning">
  The module gate (FeatureGate) is a **presentation-only** guard — the real authorization
  check always lives on the server. Even if you unhide a screen with a browser trick,
  the backend rejects the unauthorized request. So "forcing open" a module you don't own
  won't work; the right path is to buy that module. Free-core screens have no such gate
  in the first place.
</Callout>
